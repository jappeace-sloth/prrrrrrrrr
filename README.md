# prrrrrrrrr

Olympic weightlifting 1RM tracker.

This project is a trial consumer of [haskell-mobile](https://github.com/jappeace/haskell-mobile).
Its purpose is to drive haskell-mobile's API design by being a real-world user of it.
If you encounter a haskell-mobile defect while working here, open an issue upstream
rather than adding workarounds in this project.
